## 内容模型

### Profile

必填：`name`、`shortBio`。可选：`avatar`、`longBio`、`location`、`currentStatus`、公开 `links`。

### Experience

必填：`id`、`startDate`、`title`、`description`。可选：`endDate`、`organization`、`tags`、`image`、`link`。

### Game

必填：`id`、`title`、`cover`、`updatedAt`。可选：`artwork`、`platforms`、`hours`、本人确认的 `status`、`year`、`note`。

### Book

必填：`id`、`title`、`author`、`cover`、`status`、`updatedAt`。`status` 只能是“在读 / 读完 / 想读”。可选：`finishedAt`、`externalUrl`、`note`。

同步来源可选字段：`source`、`sourceId`、`addedAt`。`addedAt` 表示首次加入本站的日期，不冒充阅读日期。

### Music

必填：`id`、`title`、`artist`、`cover`、`kind`、`updatedAt`。`kind` 只能是“单曲 / 专辑”。可选：`externalUrl`、`note`。

同步来源可选字段：`source`、`sourceId`、`addedAt`。`addedAt` 表示首次加入本站的日期，不冒充实际收听日期。现有年度歌单条目可用 `featured` 保留首屏折页身份。

### Film

必填：`id`、`title`、`poster`、`updatedAt`。可选：`releaseYear`、`director`、`watchedAt`、`note`。

所有模型暂不设置评分字段；只有形成统一且经本人确认的评分体系后再增加。

## 素材与真实性规则

- 游戏时长只使用可核实公开数据；无法确认时省略。
- 游戏状态、读书状态、评价与感想必须由本人明确提供或确认，不能从时长、分享链接或平台行为推断。
- 图片、封面和海报必须来源清晰、合法且可稳定访问。
- 不托管未经授权的音乐、影片或游戏资源；音乐页只链接到原平台，不自动播放。
- 远程图片失效时保留文字和入口；游戏可回退普通封面，其他媒体可隐藏失效图片。
- 没有真实条目的分类不使用假封面、假数量或模板短评填充。
- 占位文案只能作为带明确标签的编辑提问存在，不能假装成本人经历、观点、偏好或感想。

## 本地同步边界

- V1 已实现，完整操作命令与 JSON 模板见根目录 `CONTENT_SYNC.md`。
- 目标来源：网易云公开单曲/歌单链接、微信读书公开分享链接、腾讯官方微信读书 Skill 返回的公开书架条目，以及用户主动提供的 JSON 文件。
- 流程：提取公开字段 → 显示新增/重复预览 → 用户确认 → 写入本地数据 → 本地预览 → 再决定是否提交 GitHub。
- 微信读书状态不能从公开页面可靠推断，链接导入时必须由用户明确“在读 / 读完 / 想读”。
- 微信读书 Skill 只将 `secret == 0` 的书籍作为网站候选；私密书籍名称不写入项目与长期上下文。`finishReading` 和最近阅读时间只用于生成建议，不能替代本人确认。
- “今天 / 本月新增”按首次写入本站的 `addedAt` 计算，不描述为平台上的真实收听或阅读时间。
- 不读取浏览器 Cookie，不保存账号密码，不调用未经授权的逆向接口。
